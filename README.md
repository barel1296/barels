# GROS — AI Growth Operating System

An Autonomous AI Growth Operating System for mid-size mobile game studios and subscription app companies: five super-agents (Growth Director, Intelligence, Operations, Creative, Tracking/Data) that investigate growth problems in a visible War Room, debate over inspectable evidence, and prepare executable actions — budget shifts, campaign changes, creative rotations, audience syncs — behind a human approval gate, with an architecture built to graduate to supervised autonomy.
